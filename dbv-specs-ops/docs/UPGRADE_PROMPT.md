# Prompt de actualización del proceso

Actualiza únicamente los mecanismos de `dbv-specs-ops` en este repositorio conforme a `docs/UPGRADING.md`.

Antes de editar, contrasta la versión publicada del framework con `project.config.md`, las instrucciones de Copilot, prompts, guardarraíles y documentación local. Preserva requisitos, arquitectura, decisiones, tareas, changelog y cambios de usuario. Clasifica las novedades como aplicables, opcionales o incompatibles; no instales dependencias, no cambies el runtime y no reemplaces archivos de producto. Para cualquier decisión que altere comportamiento, exposición web, privacidad o permisos, presenta un plan y solicita aprobación. Al finalizar, valida los JSON/prompts/workflows afectados y registra versión, decisiones y pruebas.
