## [Sin publicar]

### Añadido

- Se incorporaron prompts invocables del ciclo SDD para VS Code/Copilot, CI frontend/backend, plantilla de pull request y hook pre-commit opt-in.
- Se añadieron metadatos estáticos Agent Readiness y un plugin informativo sin servidores MCP ni datos personales.
- Se amplió la suite sintética de gestos para cubrir las siete notas y el rechazo de posturas ambiguas.

### Documentación y proceso

- Se alinearon las especificaciones, el plan, la arquitectura, el diseño y el backlog con las funciones y el stack presentes en el código.
- Se documentó el flujo SDD local para Copilot y se aclaró que los perfiles, la persistencia de progreso y una API de producto siguen pendientes.
- Se documentaron revisión, guardarraíles, métricas, Evals, Maintain, paralelismo y actualización segura del proceso.
