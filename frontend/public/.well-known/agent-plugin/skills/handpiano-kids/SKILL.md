# HandPiano Kids

Use this skill only to explain the public educational application. It maps hand gestures to musical notes, displays notes on a staff and piano keyboard, synthesizes audio in the browser, and offers a short practice evaluation.

Interactive practice requires a compatible browser and camera permission granted by the user. Do not request, infer, store, or transmit camera images, hand landmarks, a child's identity, age, or learning results. The public web origin does not expose an MCP tool or a product API. Do not claim that the Spring Boot health endpoint is a public learning API.

MediaPipe runtime assets are downloaded from the CDN URLs configured by the application; do not claim that all network activity is local.
